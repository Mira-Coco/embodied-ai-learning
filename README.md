## 什么是具身智能

具身智能（Embodied AI）研究的是智能体如何通过身体、传感器和环境交互来完成任务。

与只处理文本或图像的 AI 不同，具身智能强调：

- 感知：从相机、深度相机、激光雷达、IMU、力传感器等获取环境信息。
- 决策：根据目标、状态和历史信息选择下一步动作。
- 控制：把高层动作转化为机器人可执行的运动指令。
- 交互：在真实或仿真环境中通过试错、模仿或学习不断改进能力。

典型任务包括机械臂抓取、移动机器人导航、人形机器人行走、双臂协作、视觉语言动作控制等。

## 学习路线

建议按以下顺序学习，每个阶段都尽量做到“能运行、能修改、能解释”。

### 1. 基础阶段

- Python 基础：脚本、虚拟环境、常用数据结构、文件读写。
- Linux 基础：终端、包管理、环境变量、SSH、常用命令。
- Git 基础：clone、commit、branch、pull request。
- 数学基础：线性代数、坐标变换、概率、优化基础。

### 2. 机器人基础

- 机器人组成：传感器、执行器、控制器、计算平台。
- 坐标系与 TF：世界坐标系、机器人坐标系、相机坐标系。
- 运动学基础：关节、连杆、正运动学、逆运动学。
- 控制基础：位置控制、速度控制、力矩控制、PID。

### 3. ROS 2 入门

- 理解 ROS 2 的节点、话题、服务、动作和参数。
- 学习 `rclpy` 或 `rclcpp` 编写基础节点。
- 使用 `ros2 topic`、`ros2 node`、`ros2 service` 调试系统。
- 学习 URDF、RViz、TF2 和 rosbag。

### 4. 仿真与 Isaac Sim

- 安装并运行 Isaac Sim。
- 导入 URDF 或 USD 机器人模型。
- 配置相机、激光雷达、IMU 等传感器。
- 连接 ROS 2 Bridge，实现仿真与 ROS 2 通信。
- 使用 Isaac Lab 学习强化学习、模仿学习和机器人策略训练。

### 5. VLA 与机器人学习

VLA（Vision-Language-Action）模型将视觉、语言和动作连接起来，使机器人能够根据图像观察和自然语言指令生成动作。

学习重点：

- 视觉编码：理解图像或视频中的物体、场景和状态。
- 语言理解：解析人类指令和任务目标。
- 动作生成：输出机械臂、移动底盘或人形机器人的动作。
- 数据集：学习机器人轨迹、遥操作数据和仿真数据的组织方式。
- 微调与评估：理解模型如何适配具体机器人和任务。

### 6. 人形机器人方向

- 学习人形机器人的自由度、关节结构和运动约束。
- 理解全身控制、平衡控制、步态生成和运动规划。
- 关注仿真训练到真实部署的差异，例如延迟、摩擦、传感器噪声和硬件限制。
- 从开源仿真、ROS 2 接口和官方 SDK 示例开始，不直接在真实机器人上运行未经验证的控制策略。

## ROS 2 / Isaac Sim / VLA

### ROS 2

ROS 2 是机器人软件系统的基础设施，适合用来组织机器人中的感知、规划、控制和可视化模块。

初学者应优先掌握：

- 节点通信：Topic、Service、Action。
- 数据类型：Message、Service、Action definition。
- 构建工具：colcon、ament、workspace。
- 调试工具：RViz、rqt、rosbag2、TF2。
- 工程习惯：一个功能一个包，接口清晰，日志可读。

### Isaac Sim

Isaac Sim 是面向机器人开发的高保真仿真平台，适合在没有真实机器人的情况下学习感知、控制和数据生成。

建议学习路径：

1. 运行官方示例场景。
2. 导入一个简单机器人模型。
3. 添加相机或激光雷达传感器。
4. 使用 ROS 2 Bridge 发布传感器数据。
5. 在 ROS 2 中订阅数据并进行可视化。
6. 使用 Isaac Lab 尝试训练简单策略。

### VLA

VLA 模型是连接大模型与机器人动作的重要方向。它的核心问题是：给定图像观察和语言指令，模型如何输出机器人可以执行的动作。

学习时不要只关注模型结构，还要关注：

- 数据从哪里来。
- 动作空间如何定义。
- 模型输出如何映射到机器人控制接口。
- 仿真结果如何迁移到真实机器人。
- 评估指标如何设计。

## 学习建议

- 先跑通最小示例，再阅读复杂源码。
- 每次只解决一个具体问题，不同时引入太多工具。
- 记录所有报错、环境版本和解决步骤。
- 优先学习官方文档和活跃开源项目。
- 对真实机器人控制保持谨慎，先在仿真中验证。
